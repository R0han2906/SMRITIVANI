# Manual demo outline

1. On one browser, create a caregiver account, finish the elderly profile, and open Dashboard.
2. Generate a six-digit pairing code. Note its 15-minute expiry and keep the code private.
3. Open the app in a separate private browser window on another device/session. Choose patient mode, enter the code on the large keypad, and confirm that Elderly Home opens without email or password.
4. Reopen the paired device and confirm it bypasses pairing.
5. Tap the large microphone and try “mujhe dawai dikha dijiye”, “beti ko phone karna hai”, “bhajan sunna hai”, “akela lag raha hai”, and “madad, main gir gayi”.
6. On the caregiver browser, refresh Dashboard, review voice interactions and safety alerts, acknowledge an alert, and open Daily Log.
7. In Settings, inspect last-active device status and try device revocation/re-pairing.

This is a guide for the caregiver to perform. No manual run-through was performed by the coding agent.
