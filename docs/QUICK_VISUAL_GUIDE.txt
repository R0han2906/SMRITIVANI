TROUBLESHOOTING QUICK REFERENCE
================================================================================

Problem: Servers won't start
Solution: Check Python/Node installed, check ports not in use

Problem: Code entry fails
Solution: Generate new code (old one expired after 15 min)

Problem: Device doesn't pair
Solution: Check backend logs, try with new code

Problem: Page shows blank
Solution: F12 → Console for errors, check JWT token exists

Problem: Refresh redirects to pairing
Solution: Device token lost, check localStorage

Problem: No sync between tabs
Solution: Check backend is running, check network errors
